## 🚀 Featured Projects

### 🚍 [IKDrive](https://github.com/lexycon002/ikdrive)

**Staff Transportation Reservation & Check-in Platform**

A mobile application for staff bus reservations, seat selection, digital boarding passes, and passenger check-ins.

**Technical highlights:**
- Cross-platform mobile development with React Native, Expo, and TypeScript.
- Seat reservation workflows with database-level concurrency protection.
- PostgreSQL functions and Remote Procedure Calls (RPCs) using Supabase.
- QR code boarding pass validation and passenger check-in.
- Time-restricted booking windows using West Africa Time.
- Automated processing of expired reservations and no-shows.
- Administrative workflows for passenger management and reporting.
- Companion web landing page built with Next.js.

**Tech:** React Native, Expo, TypeScript, Next.js, PostgreSQL, Supabase.
